# Deep Learning Lab (Semester 6)

This repository contains the lab assignments and projects for the Deep Learning course (Semester 6). All implementations are done in Python using Jupyter Notebooks, primarily focusing on PyTorch.

**Author:** Nabeel Shan

## 📚 Lab Contents

| Lab | Topic | Description |
| :--- | :--- | :--- |
| **Lab 1** | [Single Layer Perceptron](Lab1_SingleLayerPerceptron_NabeelShan.ipynb) | Implementation of a basic Single Layer Perceptron model. |
| **Lab 2** | [PyTorch Fundamentals](Lab2_PyTorch_Fundamentals_NabeelShan.ipynb) | Introduction to PyTorch tensors, operations, and basic neural network building blocks. |
| **Lab 3** | [Music Generation with RNNs (LSTM)](Lab3_MusicGeneration_RNNs(LSTM)_NabeelShan.ipynb) | Using Recurrent Neural Networks, specifically Long Short-Term Memory (LSTM) networks, for generating music sequences. |
| **Lab 4** | [CNN Digit Classification](Lab4_CNN_DigitClassification_NabeelShan.ipynb) | Building a Convolutional Neural Network (CNN) to classify handwritten digits (e.g., MNIST). |
| **Lab 5** | [CNN with Regularization](Lab5_CNN_with_Regu_L1_L2_Dropout_Combined_NabeelShan.ipynb) | Advanced CNN implementation incorporating L1/L2 regularization and Dropout techniques to prevent overfitting. |

## 🛠️ Technologies Used
* **Python 3.x**
* **PyTorch** (Deep Learning Framework)
* **Jupyter Notebook** (Interactive Development Environment)
* **NumPy / Pandas / Matplotlib** (Data manipulation and visualization)

## 🚀 How to Run
1. Clone this repository to your local machine.
2. Ensure you have Python and Jupyter Notebook installed.
3. Install the required dependencies (e.g., `pip install torch torchvision numpy matplotlib`).
4. Open the terminal in the repository folder and run:
   ```bash
   jupyter notebook
   ```
5. Open the desired `.ipynb` file from the Jupyter interface and run the cells sequentially.
